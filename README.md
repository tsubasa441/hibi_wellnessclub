# Hibi - フィットネスコミュニティアプリ

## ミッション

> **「あなたの日々をもっと豊かに」**


ストレスを抱えながら生きる現代人に対して、運動を中心としたウェルネス体験を行う場を提供し、運動・新奇体験・人との繋がりを持って人生の幸福度を高めてもらうことを目的としている。
日々の生活に飽きている人。社内以外のつながりがない人。自己肯定感を上げたい人。達成感を得たい人。前向きな気持ちで生きていきたい人。そんな人たちが、フィットネスを通じて豊かな日常を手に入れるためのコミュニティアプリ。

## サービス概要

Hibi はヨガ・トレーニング・ランニング・ボクシングなど月 4〜5 回のフィットネスイベントを運営するコミュニティの予約・管理・エンゲージメント向上アプリ。

| 項目 | 内容 |
|------|------|
| サービス名 | Hibi |
| ターゲット | 20〜40 代の社会人（想定 100〜500 人規模） |
| 開催頻度 | 月 4〜5 回 |
| イベント種別 | ヨガ・トレーニング・ランニング・ボクシング |

## 解決する課題

- 予約・決済の属人化（現状：手作業管理）
- 参加者のエンゲージメント低下・継続率の低さ
- 各イベントの残り枠がわからない
- 直前キャンセルによる参加枠の無駄（2日前までのキャンセルは返金あり、1日前・当日は返金対象外）

## 主な機能（MVP）

1. **イベント予約・事前決済**（Square / PayPay）
2. **累計参加数の可視化**（自己肯定感・達成感）
3. **紹介システム**（紹介コード・ポイント還元）
4. **リファラルツリー**（自分の紹介によって参加した人たちの見える化・自己効力感の可視化）
5. **ゲーミフィケーション**（バッジ・ランキング・ストリーク）
