## 1. プロジェクト概要

### 背景

Hibi はヨガ・トレーニング・ランニング・ボクシング・ピラティスなど月 4〜5 回のフィットネスイベントを運営するコミュニティ。現在、予約・決済・参加履歴・紹介導線が整備されておらず、運営の属人化と参加者エンゲージメント低下が課題。今後、イベント回数の増加、法人への導入など、さらにスケールさせていく際に、属人化の解消、参加者のエンゲージメント向上、法人に導入するにあたって実績の蓄積・ビジネスとしての信頼の構築が必須。

### 目的

- 参加者が『Hibiの一員であること』を自慢したくなり、自分自身のライフスタイルに誇りを持てる状態をつくる・運動を通じて自身の成長を実感できる状態を作る
- エンゲージメントの向上
- イベント参加の継続率アップ
- 自己実現欲求の最大化（自分が何者かでいられていること・誰かの役に立てていることの証明）

### 対象ユーザー

フィットネスに興味のある 20〜40 代の社会人。想定 100〜500 人規模。

## 2. 機能要件

### A. イベント予約・決済

- イベント一覧表示（日付・種別・定員・残席数）
- イベント詳細ページ（残席数をリアルタイム表示）
- Square または PayPay での事前決済
- 予約確認メール送信
- キャンセルポリシー：イベント2日前までキャンセル可、1日前・当日はキャンセル自体は可能だが返金対象外
- キャンセル時の返金フロー：Square / PayPay は API で自動全額返金、無料イベントは返金なし
- イベントごとの選択項目：管理者が任意個数（最大10）設定できるプルダウン選択項目。ユーザーはイベント詳細画面で回答してから予約する。項目ごとに「必須/任意」「単一/複数選択」を設定可能。金額・ポイント・返金には影響しない情報項目。回答は参加者一覧・CSV に表示される

### B. 累計参加数

- 参加回数の可視化（プロフィール画面）
- 参加履歴一覧（スコープ外）

### C. 紹介システム

- ユーザーごとのユニーク紹介コード発行
- 紹介コード経由で新規登録・初回参加完了 → 紹介者にポイント付与
- 紹介実績数の表示（紹介人数・初回参加完了数、履歴リスト）

### D. ゲーミフィケーション

- ポイント制度（参加・紹介でポイント獲得）
- バッジシステム（達成条件別）

### E. ジャーナル機能

- 毎日の心身の健康状態・気持ちをログとして残せる機能（ホーム画面からのクイック入力のみ）
- 振り返り画面・グラフ表示はユーザー向けには提供しない
- journals テーブルのデータは将来の法人（ToG）向けデータ提供・健康影響レポートの原資として保管する

### F. 管理者機能

- イベント作成・編集・削除（削除は論理削除。`status` を `cancelled` に更新し、予約履歴は保持する）
- イベントの選択項目（`event_options`）の設定（項目名・選択肢・必須/任意・単一/複数選択）。編集時は置き換え方式
- 参加者一覧・CSV エクスポート（選択項目の回答を含む。選択項目のラベルが CSV の動的列になる）
- `profiles.is_admin` で管理者を判定。付与はアプリ内UIではなく Supabase Studio から手動で行う運用（@docs/authdesign.md 参照）

## 3. 非機能要件

| 項目 | 内容 |
|------|------|
| 想定ユーザー数 | 100〜500人 |
| レスポンシブ | スマホファースト |
| 言語 | 日本語 UI |
| 認証 | Supabase Auth |
| セキュリティ | Row Level Security |
| 可用性 | 99% 以上 |

## 4. 画面一覧

| 画面名 | URL | 説明 | 優先度 | 状態 |
|--------|-----|------|--------|------|
| トップ | `/` | アプリの入口・ビーチ背景・コンセプトコピー | 高 | 完成 |
| ログイン・新規登録 | `/login` | SIGN IN / SIGN UP タブ切り替え（紹介コード入力欄あり） | 高 | 完成 |
| 登録完了 | `/register-complete` | 新規登録完了後の案内画面 | 中 | 完成 |
| ホーム | `/home` | ログイン後ランディング・次回イベント表示 | 高 | 完成 |
| イベント一覧 | `/events` | 開催予定イベントの一覧・種別バッジ | 高 | 完成 |
| イベント詳細 | `/events/[id]` | 詳細情報・残席数・予約ボタン | 高 | 完成 |
| 決済 | `/events/[id]/checkout` | Square / PayPay 決済 | 高 | 完成 |
| 予約済みイベント | `/bookings` | 予約済みイベント一覧・キャンセル | 中 | 完成 |
| Impact | `/impact` | プロフィール・累計参加数・バッジ・紹介機能 | 高 | 完成 |
| パスワード再設定 | `/auth/reset-password` | パスワードリセットメールのリンクから新パスワードを設定 | 中 | 完成 |
| 管理者：イベント一覧 | `/admin/events` | 公開中・下書きイベントの一覧・新規作成導線（削除済みは一覧に表示しない。管理者のみ） | 中 | 完成 |
| 管理者：イベント作成 | `/admin/events/new` | イベント新規作成フォーム（管理者のみ） | 中 | 完成 |
| 管理者：イベント編集 | `/admin/events/[id]` | イベント編集フォーム・削除（管理者のみ） | 中 | 完成 |
| 管理者：参加者一覧 | `/admin/events/[id]/participants` | イベント参加者一覧・CSV エクスポート（管理者のみ） | 中 | 完成 |

### BottomNav 構成

認証済み全画面に共通の下部ナビゲーション。

| タブ名 | アイコン | 遷移先 |
|--------|---------|--------|
| Home | 家 | `/home` |
| Event | カレンダー | `/events` |
| Impact | ハート | `/impact` |
